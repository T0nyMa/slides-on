# Vector Illustration — AI Image Style Definition

Flat vector illustration style. Clean geometric shapes, crisp outlines, modern app-like aesthetic. Bold, colorful, scalable.

## Style Lock (跨页复用)

```text
Clean flat vector illustration style — crisp, modern, geometric.
Solid flat color fills with NO gradients, NO textures, NO 3D effects.
Bold clean outlines (1–2px visual weight) in dark navy #1A1D2E or matching darker shade.
Geometric shapes: rounded rectangles (8–12px corner radius), perfect circles, clean polygons.
Flat color palette: primary blue #4A90D9, coral #FF6B6B, mint #4ECDC4, warm yellow #FFD93D, purple #9B59B6, dark navy #1A1D2E.
Background: light cream #FCFAF5 or solid light grey #F0F2F5, with optional simple geometric decorative shapes.
Generous whitespace (35–45%). Central illustration 50–60% page width.
Simple iconography: clean minimalist icons with 2–3 color fills.
Subtle drop shadow on key cards (flat shadow — a solid offset shape, NOT blurred).
No gradients, no textures, no photorealistic, no hand-drawn wobble, no 3D rendering, no complex backgrounds, no thin lines, no many characters (max 1 simple flat avatar).
Consistent 2px line weight throughout. Same geometric precision across all pages.
```

## Visual Elements

- Clean geometric shapes with crisp outlines — rounded rectangles, circles, triangles
- Flat solid color fills throughout — absolutely no gradients or textures
- Simple modern iconography in 2–3 colors per icon, minimal detail
- Flat drop shadows: solid offset rectangles below key cards, NO blurred shadows
- Thin consistent outlines (1–2px visual) on all shapes, dark navy #1A1D2E
- Simple geometric background decorations: scattered circles, dots, triangles at low opacity
- Abstract character avatars: simple geometric head + body, flat colors, minimal features
- Card modules: rounded rectangles with solid fill + thin outline + optional flat shadow
- Simple line connectors between nodes: straight or 45° angled, no curves
- Clean horizontal rules and dividers: single-color lines, full width

## Typography

- Clean sans-serif lettering — geometric, modern, no handwriting
- Bold titles, regular weight body text
- NO serif, NO cursive, NO handwritten, NO decorative fonts
- Text integrated as clean flat shapes when baked-in

## Composition

- Modular grid-based layout: 2–3 cards per row in clean alignment
- Generous whitespace (35–45%)
- Central illustration compact: 50–60% page width
- Consistent spacing rhythm: equal margins, equal gaps between cards
- Fixed shell: background color, line weight, corner radius, icon style
- Vary card content and layout grid across pages

## Negative Constraints

- NO gradients, NO textures, NO noise, NO grain
- NO photorealistic rendering, NO 3D perspective
- NO hand-drawn wobble, NO irregular lines — everything is precise geometric
- NO blurred shadows, NO soft edges — only flat solid offset shadows allowed
- NO thin hairline strokes (minimum 1.5–2px visual weight)
- NO many characters (max 1 simple flat avatar)
- NO complex backgrounds, NO photographic elements
- NO calligraphy, NO brush strokes, NO watercolor
- NO neon, NO glow effects
- NO crowded compositions — keep it clean and spacious
