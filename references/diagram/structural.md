# Structural Diagram（结构图）

用于展示组织架构、分类体系、层级关系、拓扑结构或概念分解——所有以"归属关系"为核心的图型。

## 适用场景

| 场景 | 示例 |
|------|------|
| 组织架构 | 公司 → 部门 → 团队 → 个人 |
| 分类体系 | 推荐系统 → 召回/粗排/精排/重排 → 各阶段模型 |
| 思维导图 | 中心主题 → 一级分支 → 二级细节 |
| 文件目录树 | 根目录 → 子目录 → 文件 |
| 概念分解 | WBS 工作分解、产品功能树 |
| 继承/实现关系 | 接口 → 抽象类 → 具体实现类 |

## 典型视觉结构

| 元素 | SVG 形状 | 说明 |
|------|---------|------|
| 根节点 | `<rect rx="10">` | 顶层概念，居中顶部或左对齐 |
| 中间节点 | `<rect rx="6">` | 层级节点，填充色逐层变浅 |
| 叶子节点 | `<rect rx="4">` 或 `<ellipse>` | 最细粒度，可用圆角或椭圆区分 |
| 连接线 | `<path>` 或 `<polyline>` | 直角折线或曲线连接父子节点 |
| 包含框 | `<rect>` 虚线/浅填充 | 将同层组件框在一起，标注层级名称 |
| 横线/括号 | `<path>` | 用于分类标注的辅助线 |

## 布局模式

```
【树形 — 自上而下（最常见）】
                ┌──────┐
                │ Root │
                └──┬───┘
          ┌────────┼────────┐
      ┌───▼───┐ ┌─▼──┐ ┌───▼───┐
      │ Child │ │ ...│ │ Child │
      └───┬───┘ └────┘ └───┬───┘
     ┌────┼────┐       ┌────┼────┐
   ┌▼──┐┌▼──┐┌▼──┐  ┌▼──┐┌▼──┐┌▼──┐
   │...││...││...│  │...││...││...│
   └───┘└───┘└───┘  └───┘└───┘└───┘

【思维导图 — 中心放射】
         ┌──────┐
    ┌────┤      ├────┐
    │    │Center│    │
 ┌──▼──┐ └──────┘ ┌──▼──┐
 │     │           │     │
 └──┬──┘           └──┬──┘
    │                 │
 ┌──▼──┐          ┌──▼──┐
 │     │          │     │
 └─────┘          └─────┘

【层级列表 — 缩进式】
  Layer 1  ┌─────────────────────────┐
           └─────────────────────────┘
  Layer 2    ┌─────────┐ ┌─────────┐
             └─────────┘ └─────────┘
  Layer 3      ┌────┐ ┌────┐ ┌────┐
               └────┘ └────┘ └────┘
```

## z-order 分层规则

```
Layer 1: 背景 (Background)
  └── 深色画布填充 (#0f172a)

Layer 2: 区域/包含边界 (Region/Containment Boundaries)
  └── 虚线或低透明度填充框，框住同一层级的节点
  └── 层级标签（如"数据层""模型层"）

Layer 3: 连接线 (Connection Lines)
  └── 父节点到子节点的连接线
  └── 直角折线 (.├── 或 └── 形状) 或贝塞尔曲线
  └── 连接线通常不加箭头（表达归属而非流向）

Layer 4: 遮罩矩形 (Mask Rectangles)
  └── 连接线进入节点处的遮罩，保持边框完整

Layer 5: 节点框 (Node Boxes)
  └── 根节点、中间节点、叶子节点
  └── 按层级使用不同填充色深度

Layer 6: 文本标注 (Text Labels)
  └── 节点内文字（居中）
  └── 层级标签（在包含框左上角）
  └── 附加说明（节点下方小字）

Layer 7: 图例 (Legend)
  └── 颜色/形状 → 层级含义

Layer 8: 标题 (Title)
  └── 顶部居中或左上角
```

## 层级深度配色

按层级深度递进使用 8 色系统：

| 层级 | 色号 | 填充 | 说明 |
|------|------|------|------|
| Level 0 (Root) | Primary (#60a5fa) | 80% 不透明 | 顶层概念 |
| Level 1 | Secondary (#a78bfa) | 60% 不透明 | 一级分支 |
| Level 2 | Tertiary (#34d399) | 45% 不透明 | 二级分支 |
| Level 3 | Alert (#fb923c) | 35% 不透明 | 三级 |
| Level 4+ | Connector (#94a3b8) | 25% 不透明 | 叶子节点 |
| 连接线 | Connector (#94a3b8) | stroke-width: 1.5 | 灰色，不分层 |
| 包含框 | Connector (#94a3b8) | stroke-dasharray: 6,3 | 虚线边框 |

## 何时选择 Structural Diagram

- **选择此类型**：需要展示"A 包含 B，B 包含 C"或"中心概念如何拆解为子概念"的层级关系
- **不用此类型**：如果需要表达组件间数据/控制流动，用 Architecture 或 Flowchart

## 与其他图型对比

| 对比项 | Structural | Architecture | Flowchart | Sequence |
|--------|:----------:|:-----------:|:---------:|:--------:|
| 核心关系 | 归属/父子 | 依赖/调用 | 顺序/分支 | 消息序列 |
| 连线上箭头 | 通常无 | 有（表示方向） | 有（表示流向） | 有（表示发送） |
| 层级语义 | 多层嵌套 | 最多 3-4 层 | 无层级概念 | 无层级概念 |
| 典型形状 | 圆角矩形 | 方框+圆柱 | 5+ 种形状 | 生命线 |
