# Texture 维度

Texture（质感）描述幻灯片的画面纹理和视觉深度，是用户第一眼的直觉感受。

## 可选值

### clean（平滑）

**视觉描述**: 纯色或微妙渐变背景，无可见纹理。强调内容本身，色彩作为安静的氛围烘托。

**设计特征**:
- 纯色背景或 1-2 色渐变
- 无图案、无噪点、无网格线
- 阴影轻度或无阴影
- 元素边缘锐利

**匹配主题**: `minimal-white.css`, `corporate-clean.css`, `swiss-grid.css`, `catppuccin-latte.css`, `solarized-light.css`, `nord.css`, `catppuccin-mocha.css`, `dracula.css`, `tokyo-night.css`, `pitch-deck-vc.css`, `news-broadcast.css`, `arctic-cool.css`

**使用 Preset**: bold-editorial, corporate, dark-atmospheric, editorial-infographic, minimal, notion, scientific, vector-illustration

---

### grid（网格）

**视觉描述**: 蓝图网格线、点阵或工程图纸背景。传递技术感、精确感和工程感。

**设计特征**:
- 等距网格线或点阵覆盖
- 蓝色或青色为主色调
- 白色或深蓝底色
- 常配合等宽字体使用

**匹配主题**: `blueprint.css`, `engineering-whiteprint.css`, `sharp-mono.css`

**使用 Preset**: blueprint, intuition-machine

---

### organic（有机）

**视觉描述**: 自然流动的曲线、柔和的噪点纹理或不规则形状。传递手工感、艺术感和自然气息。

**设计特征**:
- 不规则纹理或渐变
- 噪点叠加
- 柔和的色彩过渡
- 曲线装饰元素

**匹配主题**: `midcentury.css`, `sunset-warm.css`, `aurora.css`, `rainbow-gradient.css`, `glassmorphism.css`

**使用 Preset**: fantasy-animation, vintage, watercolor

---

### pixel（像素）

**视觉描述**: 可见像素网格、低分辨率风格、8-bit 或 16-bit 游戏美学。传递复古电子游戏感。

**设计特征**:
- 像素化背景图案
- 明确的像素网格可见
- 高饱和色彩
- 像素字体

**匹配主题**: `retro-tv.css`, `y2k-chrome.css`

**使用 Preset**: pixel-art

---

### paper（纸张）

**视觉描述**: 模拟真实纸张纹理：牛皮纸、方格纸、黑板、水彩纸等。传递教学感、手工感和亲切感。

**设计特征**:
- 纸张纹理背景（噪点/纤维）
- 偏暖或偏米色基调
- 手写字体或衬线字体
- 不规则边缘或阴影模拟纸张厚度

**匹配主题**: `academic-paper.css`, `editorial-serif.css`, `japanese-minimal.css`, `gruvbox-dark.css`

**使用 Design**: chalkboard, hand-drawn-edu, sketch-notes

---

## Texture 快速选择

| 场景 | 推荐 Texture |
|------|-------------|
| 技术架构、系统设计 | grid |
| 商业演示、企业汇报 | clean |
| 学术论文、研究报告 | clean 或 paper |
| 教学课件、培训材料 | paper |
| 创意提案、品牌设计 | organic 或 clean |
| 游戏/像素文化主题 | pixel |
| 儿童教育、手绘风格 | paper |
