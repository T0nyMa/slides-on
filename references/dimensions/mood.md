# Mood 维度

Mood（氛围）描述幻灯片的情感基调和视觉氛围，决定配色方案的核心走向。

## 可选值

### professional（专业）

**视觉描述**: 正式、克制、可靠。使用企业色（蓝、灰、深蓝），避免过度装饰。

**典型配色**:
- 主色: 深蓝 `#1a3a5c` / 海军蓝 `#0d2b4e`
- 强调色: 企业蓝 `#2563eb` / `#1d4ed8`
- 背景: 白或极浅灰
- 文字: 深灰到黑

**使用 Preset**: corporate

**匹配场景**: 商务汇报、融资路演、年度总结、客户提案

---

### warm（温暖）

**视觉描述**: 邀请感、友好、亲近。使用暖色系（橙、红、黄、暖棕）。

**典型配色**:
- 主色: 暖橙 `#e07b39` / 陶土红 `#c1442a`
- 强调色: 琥珀 `#f59e0b`
- 背景: 米白 / 奶油 / 牛皮纸
- 文字: 暖棕或深棕

**使用 Preset**: hand-drawn-edu, sketch-notes, vintage, watercolor

**匹配场景**: 教学课件、团队内部分享、创意工作坊、个人博客

---

### cool（冷静）

**视觉描述**: 抽离、现代、理性。使用冷色系（蓝、青、绿、灰）。

**典型配色**:
- 主色: 冷蓝 `#3b82f6` / 青 `#06b6d4`
- 强调色: 霓虹青 `#00f0ff`
- 背景: 白或冷灰
- 文字: 深灰

**使用 Preset**: pixel-art

**匹配场景**: 数据分析、技术文档、产品规格说明

---

### vibrant（活力）

**视觉描述**: 能量充沛、大胆、引人注目。使用高饱和色，强对比，视觉冲击力强。

**典型配色**:
- 主色: 亮红 `#ef4444` / 亮黄 `#facc15` / 亮橙 `#f97316`
- 强调色: 高饱和对比色
- 背景: 白或黑
- 文字: 深黑或纯白

**使用 Preset**: bold-editorial, fantasy-animation, vector-illustration

**匹配场景**: 产品发布、品牌宣传、创意提案、设计展示

---

### dark（暗色）

**视觉描述**: 神秘、戏剧性、专注。使用深色背景，亮色文字和强调色。适合沉浸式体验。

**典型配色**:
- 主色: 纯黑 `#0a0a0a` / 深蓝黑 `#0f1117`
- 强调色: 霓虹蓝 `#00d4ff` / 紫色 `#a855f7`
- 背景: 深黑到深灰渐变
- 文字: 白或浅灰

**使用 Preset**: blueprint, chalkboard, dark-atmospheric, intuition-machine

**匹配场景**: 技术分享、代码演示、产品技术架构、沉浸式演讲

---

### neutral（中性）

**视觉描述**: 客观、冷静、无情绪偏向。使用低饱和色，以黑白灰为主，强调内容理性。

**典型配色**:
- 主色: 中灰 `#6b7280` / 石板灰 `#475569`
- 强调色: 极低饱和的蓝或绿
- 背景: 白或极浅灰
- 文字: 深灰 `#1f2937`

**使用 Preset**: editorial-infographic, minimal, notion, scientific

**匹配场景**: 学术报告、研究论文、数据分析报告、文档展示

---

## Mood 快速选择

| 场景 | 推荐 Mood |
|------|----------|
| 商业提案、客户汇报 | professional |
| 学术会议、论文答辩 | neutral |
| 技术分享（日间） | neutral 或 cool |
| 技术分享（晚间/线上） | dark |
| 教学课件 | warm |
| 产品发布 | vibrant |
| 创意展示 | vibrant |
| 团队周报 | neutral |
| 个人博客/分享 | warm |
