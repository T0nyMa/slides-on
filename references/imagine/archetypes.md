# Slide Archetypes — Universal Composition Templates

10 种语义版式的构图模板。纯结构描述（几何布局、节点数量、流向、留白），**不含任何视觉风格**。
视觉风格由 `style-definitions/{design}.md` 的 `style_lock` 提供。

Assembly 规则：`Layer 3 = Archetype 模板 × style_lock`

---

## 1. Cover Metaphor（封面隐喻）

**适用**：Deck 开篇或章节起始。一个强概念图 + 标题占位区。

**通用结构**：
- 一个居中的核心隐喻对象，占页面宽度的 50–55%
- 上方 25–30% 区域留白，为标题占位
- 可选：隐喻对象下方一条简短副标题线或装饰分割线
- 可选：页面底部角落一个微小角色（读者代理），仅用于比例参照

**节点数**：1 个主体对象
**流向**：无 — 静态、居中
**留白**：四周宽边距（30–40% 空白）

---

## 2. Single Concept（单概念解释）

**适用**：定义一个术语、解释一个概念。

**通用结构**：
- 居中主概念节点（标签 + 简图）
- 2–4 个支持性注释围绕主节点排列（上下或左右）
- 每个注释用细连接线指向主节点
- 可选：一个小图标或隐喻简图位于主节点内

**节点数**：1 中心 + 2–4 注释
**流向**：中心辐射
**留白**：25–35%

---

## 3. Left-Right Contrast（左右对比）

**适用**：错误 vs 正确、旧 vs 新、前 vs 后、A vs B。

**通用结构**：
- 左右两个区域，中间用竖线 / 箭头 / 空隙分隔
- 左侧：代表旧/错误/前（可以视觉上更凌乱、更暗、更碎）
- 右侧：代表新/正确/后（更整洁、更亮、更有结构）
- 底部 1 条简短结论标注
- 两个区域各含 1–3 个子节点

**节点数**：2 组 × 1–3 子节点
**流向**：左→右
**留白**：20–30%

---

## 4. Horizontal Process（水平流程）

**适用**：步骤、流水线、阶段推进。

**通用结构**：
- 一条从左到右的主轴线（线或箭头链）
- 4–7 个节点均匀分布在轴线上
- 每个节点：上方标签 + 中心简图 + 下方简短说明
- 节点间用细箭头连接
- 1–2 个注释框浮在轴线上下

**节点数**：4–7 个主节点
**流向**：左→右
**留白**：25–35%

---

## 5. Circular Mechanism（循环机制）

**适用**：反馈循环、迭代过程、Agent 循环。

**通用结构**：
- 3–6 个节点排列成环
- 节点间用弧形箭头顺时针连接
- 中心放置机制名称或核心标签
- 边缘放置退出条件或风险标注（1–2 个小型注释）

**节点数**：3–6 个环状节点
**流向**：顺时针环形
**留白**：30–40%

---

## 6. Branching Map（分支决策图）

**适用**：决策树、条件分支、场景选择。

**通用结构**：
- 顶部或左侧一个起始决策节点（菱形或圆角矩形）
- 3–5 条分支线从决策点散开（树状展开）
- 每个分支端点是条件标签 + 结果简述
- 分支线可以标注简短条件（if/else 逻辑）

**节点数**：1 决策点 + 3–5 分支
**流向**：顶→下 或 中心→外
**留白**：20–30%

---

## 7. Classification Map（分类框架图）

**适用**：分类体系、概念家族、框架总览。

**通用结构**：
- 顶层一个父概念节点
- 向下展开 3–5 个子类别分支
- 每个子类别下挂 1–3 个微型标签（具体示例）
- 整体呈倒树状或层级列表状

**节点数**：1 父 + 3–5 子 + 每子 1–3 标签
**流向**：顶→下 层级展开
**留白**：20–25%

---

## 8. Matrix Table（矩阵对比表）

**适用**：多维度对比、特征矩阵、选项评估。

**通用结构**：
- 一个手绘风格网格表格
- 行标签（3–5 行）和列标签（2–3 列）
- 选中单元格内放置小型标记（✓、★、●）
- 可选：表格边缘一个微小角色

**节点数**：3–5 行 × 2–3 列
**流向**：无 — 静态表格
**留白**：25–35%

---

## 9. Main Metaphor Diagram（核心隐喻图）

**适用**：抽象系统用具体隐喻解释。如"推荐系统像图书管理员""上下文像行李箱"。

**通用结构**：
- 一个大型隐喻场景或物体占据画面中央（50–65% 宽度）
- 细箭头和标签围绕主体，标注对应关系
- 3–6 个标注点将隐喻元素映射到抽象概念
- 极少（最多 1 个）微型角色

**节点数**：1 主体 + 3–6 标注
**流向**：主体居中 + 标注环绕
**留白**：30–40%

---

## 10. Takeaway（总结收束）

**适用**：最后一页、核心结论、行动号召。

**通用结构**：
- 1 条清晰的核心判断语句（页面视觉焦点）
- 下方 2–4 条支撑性要点，缩进或小图标引导
- 底部 1 个小隐喻图标或简笔装饰
- 整体结构紧凑，不填满页面 — 留白增强结论分量

**节点数**：1 核心 + 2–4 支撑点
**流向**：顶→下 递减
**留白**：35–45%

## Archetype 选择速查表

| 内容语义 | Archetype |
|---------|-----------|
| 开篇/章节起始 | Cover metaphor |
| 定义/概念解释 | Single concept |
| 对比/前后/A vs B | Left-right contrast |
| 步骤/流水线/阶段 | Horizontal process |
| 循环/反馈/迭代 | Circular mechanism |
| 决策/条件分支 | Branching map |
| 分类/框架/体系 | Classification map |
| 多维对比/评估 | Matrix table |
| 抽象系统隐喻 | Main metaphor diagram |
| 总结/结论/行动号召 | Takeaway |

## Illustration Role 适配

当 Image Role 为 `illustration`（图不带文字，文字走 HTML 层）时：
- 所有标注、标签、标题占位区保持为**空白区域**而非具体文字
- 构图描述中标注"此区域留白，供 HTML 层叠加文字"
- 保持相同的几何布局和节点数量，但不绘制任何文字内容
