# Bold Editorial (大胆编辑)

**Style**: 大字标题 + 强对比 + 杂志感排版，视觉冲击力强，适合观点鲜明的演示
**Best for**: 品牌宣传, 产品发布, 商业路演, 观点型演讲, 设计展示

## Visual Identity
- Theme: `magazine-bold.css`
- Texture: clean
- Mood: vibrant
- Typography: editorial
- Density: dense

## Layout Preferences
- Cover: `cover`（超大标题 + 单行副标题）
- Content: `big-quote`, `bullets`, `two-column`
- Code: `code`（极简代码展示，非主要用途）
- Data: `stat-highlight`, `kpi-grid`, `chart-bar`

## Animation
- Entry: `slide-up`
- Transitions: 大字逐个滑入，戏剧性强
- Canvas FX: `word-cascade`

## Signal Keywords
产品发布, 品牌, 市场, 增长, 战略, 商业, 创意, 愿景, 设计, KPI, 收入, 融资

## When to Use
需要强观点输出和视觉冲击力的演示场景，如产品发布会、品牌提案、商业路演。大字排版在投影和屏幕上均有极好表现。

## When NOT to Use
学术报告或技术文档类内容，杂志风格会显得不够严谨，喧宾夺主。
