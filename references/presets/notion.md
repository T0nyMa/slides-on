# Notion Style (Notion风格)

**Style**: Notion 式白底黑字 + 模块卡片 + 图标点缀，组织化、可操作的信息管理风格
**Best for**: 内部周报, 项目计划, OKR 跟踪, 知识库, 团队协作文档, 项目管理

## Visual Identity
- Theme: — (custom: Notion 白底 `#ffffff`，黑色主文字，灰色辅助，Emoji 图标装饰，卡片模块带浅灰边框)
- Texture: clean
- Mood: neutral
- Typography: geometric
- Density: balanced

## Layout Preferences
- Cover: `cover`（Emoji + 标题 + 简要描述）
- Content: `todo-checklist`, `bullets`, `three-column`
- Code: `code`（Notion 风格代码块）
- Data: `table`, `kpi-grid`, `chart-bar`

## Animation
- Entry: `fade-in`
- Transitions: 极简淡入
- Canvas FX: none

## Signal Keywords
周报, 进展, OKR, 复盘, todo, 计划, 项目, 任务, 协作, 知识库, 文档, Wiki, 笔记

## When to Use
团队协作和项目管理场景，Notion 风格让观众快速理解信息的组织逻辑，天然与文档文化衔接。

## When NOT to Use
品牌宣传或创意展示，Notion 风格过于"工具化"，缺乏情感和视觉冲击力。
