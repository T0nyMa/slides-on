# Corporate (企业专业)

**Style**: 企业蓝白配色 + 几何无衬线字体 + 清晰层级，专业可靠的标准商业演示风格
**Best for**: 商务汇报, 融资路演, 客户提案, 年度总结, 企业培训

## Visual Identity
- Theme: `corporate-clean.css`
- Texture: clean
- Mood: professional
- Typography: geometric
- Density: balanced

## Layout Preferences
- Cover: `cover`（标题 + 公司 logo + 日期）
- Content: `bullets`, `two-column`, `three-column`
- Code: N/A（非主要用途）
- Data: `chart-line`, `chart-bar`, `kpi-grid`, `table`

## Animation
- Entry: `slide-up`
- Transitions: 平滑滑入，克制专业
- Canvas FX: none

## Signal Keywords
产品, 市场, 增长, 收入, 战略, KPI, 商业, 企业, 融资, 路演, 客户, 方案, 汇报, 年度, 季度

## When to Use
任何需要传递专业可靠形象的商业场景。企业蓝是最安全的商业色选择，观众不会对配色有负面反应。

## When NOT to Use
创意提案或个人化内容，corporate 风格可能显得过于保守、缺乏个性。
