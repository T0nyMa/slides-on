# Sketch Notes (草图笔记)

**Style**: 牛皮纸底 + 手绘线条 + 马克笔配色 + 自由排版，模拟会议草图笔记的随性风格
**Best for**: 创意提案, 头脑风暴, 设计构思, 个人分享, 非正式演讲

## Visual Identity
- Theme: — (custom: 牛皮纸米黄色底 `#f5e6c8`，深棕墨色主线 `#3d2b1f`，马克笔强调（橙/蓝/绿/黄），不规则手绘线条边框)
- Texture: paper
- Mood: warm
- Typography: handwritten
- Density: minimal

## Layout Preferences
- Cover: `cover`（手绘标题 + 手绘装饰线）
- Content: `big-quote`, `bullets`, `two-column`
- Code: N/A
- Data: `chart-bar`, `chart-pie`（手绘风格）

## Animation
- Entry: `slide-left`
- Transitions: 从侧边滑入，模拟"翻笔记本"
- Canvas FX: `ink-drop`

## Signal Keywords
概念, 愿景, 未来, 设计, 品牌, 创意, 构思, 头脑风暴, 草图, 想法, 灵感, 提案, 自由

## When to Use
创意提案和个人化分享，特别是需要营造轻松、开放讨论氛围的场合。草图风格暗示"这还是一个过程，欢迎反馈"。

## When NOT to Use
正式商业汇报或客户交付物，草图风格显得不够专业和完整。
