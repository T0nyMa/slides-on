# Chalkboard (黑板教学)

**Style**: 模拟教室黑板效果 —— 深绿底 + 白/彩色粉笔字 + 手写风格，传递教学感和知识分享氛围
**Best for**: 教学课件, 在线课程, 知识分享, 研讨会, 培训材料

## Visual Identity
- Theme: — (custom: 黑板绿底色 `#1a3a2a`，白粉笔主色 `#e8e8e8`，彩色粉笔强调色)
- Texture: paper
- Mood: dark
- Typography: handwritten
- Density: balanced

## Layout Preferences
- Cover: `cover`（粉笔板书标题风格）
- Content: `bullets`, `two-column`, `three-column`
- Code: `code`（粉笔风格代码，非主要用途）
- Data: `chart-bar`, `chart-pie`（手绘风格图表）

## Animation
- Entry: `fade-in`
- Transitions: 缓慢淡入，模拟"书写"过程
- Canvas FX: `ink-drop`

## Signal Keywords
学习, 教学, 教程, 入门, 基础知识, 课堂, 培训, 讲解, 习题, 知识点, 课程

## When to Use
教学场景和知识分享，特别是面向初学者或需要营造轻松学习氛围的场合。黑板隐喻天然降低观众的心理门槛。

## When NOT to Use
正式商业汇报或客户提案，黑板风格过于随意，缺乏专业严肃感。
