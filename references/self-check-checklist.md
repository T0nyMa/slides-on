# Self-Check Checklist

生成 HTML 后，Claude 逐项自检。不通过则修改 HTML 重新生成。

## 通用项（卡片 + PPT 都检查）

- [ ] **视觉重心**：每页有明确的标题或视觉重心元素
- [ ] **组件密度**：每页 3-6 个组件块（< 3 留白过大，> 6 需拆页）
- [ ] **文本溢出**：无文本超出 slide 边界（overflow hidden 不算修复）
- [ ] **颜色对比度**：正文 vs 背景对比度 ≥ 4.5:1（WCAG AA）
- [ ] **CSS 变量完整性**：--bg、--text-1、--text-2、--accent 等关键变量均已定义
- [ ] **浏览器可渲染**：HTML 能在浏览器中直接打开且正确显示所有内容

## slides-card 专属

- [ ] **3:4 比例**：Deck 正确约束为 3:4（`body.portrait`）
- [ ] **cqi 字号**：所有字号使用 cqi 单位，无 px 字号
- [ ] **正文可读**：卡片正文字号 ≥ 1.5cqi（约 12px @ 3:4 基准）
- [ ] **卡片字数**：每卡片正文 ≤ 60 字
- [ ] **底部填充**：底部无大面积空白（填充率 > 45%，用 c-badge-row / c-note / c-card-soft 兜底）
- [ ] **原文完整性**：对照 source.md，所有关键信息点均已包含，无遗漏
- [ ] **grid 降级**：3:4 下多列 grid（c-grid-3 等）已降级为 ≤2 列

## slides-ppt 专属

- [ ] **标题长度**：每页标题 ≤ 10 字，单行不换行
- [ ] **Ghost Deck Test**：从 outline.md 提取所有标题，按序阅读，检查是否有逻辑断裂（详见 slides-ppt Step 1）
- [ ] **正文大小**：正文字号 ≥ 18px（投影仪可读）
- [ ] **代码行数**：代码块 ≤ 20 行，超出则只显示核心段落
- [ ] **一页一观点**：每页只传达一个论点，无"and also"
- [ ] **封面信息完整**：标题 + 副标题 + 作者/日期
- [ ] **结尾页**：包含 Conclusions（3-4 条核心结论）+ References + 联系方式
