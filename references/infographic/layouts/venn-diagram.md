# Venn Diagram

**Best for**: Intersections, commonalities, set relationships, and overlapping concepts
**Structure**: Overlapping circles (2-4), each representing a set or concept. The overlapping regions show shared elements or intersections. Non-overlapping regions show unique elements
**Elements**: Circles (one per set), set labels, intersection labels, items placed in appropriate regions, optional universal set boundary

## Content Requirements
- 2-4 sets or concepts with meaningful overlaps
- Items or descriptions for each region (unique to each set, shared between sets, shared by all)
- The intersection must be meaningful (not forced)
- Sets should be of comparable conceptual weight

## When to Use
- Showing shared characteristics between concepts
- Illustrating how ideas or domains overlap
- Finding common ground or sweet spots
- Set logic demonstrations

## When NOT to Use
- More than 4 sets (Venn diagrams become unreadable beyond 4)
- When sets have no meaningful overlap (use separate diagrams)
- When the relationships are directional rather than overlapping — use tree-branching or hub-spoke
- When precise proportions matter (area is hard to control accurately)
