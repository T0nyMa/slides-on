# Dense Modules

**Best for**: Comprehensive overviews, reference sheets, cheat sheets, and "at-a-glance" summaries with many small information blocks
**Structure**: High-density modular grid with many small similarly-sized info blocks, each containing a compact piece of information. Maximizes information per unit area
**Elements**: Grid of small cards/blocks, compact text, small icons, color coding for categories, section headers

## Content Requirements
- 8-20+ discrete information items organized into categories
- Each item is brief: a keyword + 1-2 line explanation
- Items are grouped under category headers for scannability
- Content must be reference-style (lookup) rather than narrative (read-through)

## When to Use
- Cheat sheets and quick-reference guides
- Command or shortcut reference cards
- Taxonomy or classification overviews
- Comprehensive but compact documentation summaries

## When NOT to Use
- When each item requires detailed explanation — modules become too cramped
- Narrative or argument-driven content
- When visual hierarchy conflicts with the uniform grid (all items look equally important)
