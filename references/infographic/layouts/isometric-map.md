# Isometric Map

**Best for**: Spatial relationships, 3D scenes, and physical/architectural layouts
**Structure**: An isometric (30-degree angle) 3D perspective view where objects are arranged in three-dimensional space. Can include terrain, buildings, or abstract blocks positioned in X/Y/Z axes
**Elements**: Isometric grid base, 3D block/buildings/icons, shadows for depth, connecting paths/roads, labels positioned in 3D space

## Content Requirements
- Content that benefits from spatial representation (physical layout, system topology)
- 4-15 objects that can be represented as 3D blocks or icons
- Clear spatial relationships between objects (adjacency, containment, distance)
- An underlying grid or terrain for objects to sit on

## When to Use
- Data center or infrastructure topology maps
- City/neighborhood visualizations
- System architecture with physical deployment context
- Process flows that have a spatial dimension (logistics, supply chain)

## When NOT to Use
- Abstract concepts without spatial meaning — use structural-breakdown or hub-spoke
- When 2D suffices and 3D adds unnecessary complexity
- When precise scale or measurements matter (isometric distorts perspective)
