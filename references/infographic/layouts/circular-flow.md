# Circular Flow

**Best for**: Cyclic processes, lifecycles, feedback loops, and repeating patterns
**Structure**: Nodes arranged in a circle or ring, connected by directional arrows showing the flow direction (clockwise or counter-clockwise). A central element can sit in the middle
**Elements**: Circular arrangement of nodes, directional arrows, optional center hub, step labels

## Content Requirements
- 3-8 stages in a repeating or cyclical process
- Clear directional flow (the cycle must have a logical direction)
- Each stage should naturally lead to the next, with the last connecting back to the first

## When to Use
- Continuous improvement cycles (Plan-Do-Check-Act, OODA loop)
- Lifecycle diagrams (product lifecycle, data lifecycle)
- Feedback loops in systems thinking
- Processes that repeat iteratively

## When NOT to Use
- Linear processes with a clear start and end — use linear-progression
- One-way flows that don't loop back — use funnel or linear-progression
- When stages are not meaningfully sequential
