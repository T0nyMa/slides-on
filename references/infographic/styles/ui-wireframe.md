# UI Wireframe

**Look**: UI wireframe and UX mockup aesthetic with gray boxes, placeholder elements, and annotation callouts
**Palette**: Grayscale (white, light gray, mid gray, dark gray), accent blue for annotations, red for callouts
**Mood**: Functional, in-progress, design-thinking, iterative, user-centered

## Characteristics
- Texture: Flat digital, subtle grid backgrounds, device frame mockups, placeholder image crosses
- Lines: Clean UI borders, dotted/solid outlines for different element states, annotation leader lines, grid layouts
- Typography: System UI fonts (Inter, SF Pro), lorem ipsum placeholder text, annotation handwriting or small sans-serif notes

## When to Use
- UX/UI design presentations and design reviews
- Product development "work in progress" updates
- User flow and interaction design walkthroughs
- When showing design thinking process rather than final polished output
