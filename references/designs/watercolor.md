# Watercolor (水彩艺术)

**Style**: 水彩纸纹理 + 柔色湿笔触 + 手写字体，传递艺术感和温柔情绪
**Best for**: 创意提案, 艺术展示, 情感叙事, 儿童内容, 婚礼/庆典, 个人故事

## Visual Identity
- Theme: — (custom: 水彩纸纹理底，柔和湿笔触色块（粉/蓝/紫），水彩晕染效果，不规则边缘)
- Texture: organic
- Mood: warm
- Typography: handwritten
- Density: minimal

## Layout Preferences
- Cover: `cover`（手写标题 + 水彩背景晕染）
- Content: `big-quote`, `bullets`
- Code: N/A
- Data: N/A（不常用数据展示）

## Animation
- Entry: `fade-in`
- Transitions: 缓慢淡入，模拟水彩晕开
- Canvas FX: `ripple`, `ink-drop`

## Signal Keywords
艺术, 情感, 故事, 温柔, 自然, 花, 婚礼, 庆典, 儿童, 手工, 创意, 灵感

## When to Use
以情感和艺术表达为核心的演示。水彩风格在女性向、儿童向和艺术类受众中接受度很高。

## When NOT to Use
技术文档、数据分析或商业汇报。水彩风格过于柔和，缺乏技术内容所需的精确感和权威感。
