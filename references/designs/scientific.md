# Scientific (科学学术)

**Style**: 学术白底 + 衬线标题 + 数据图表优化，遵循学术演示规范的严谨科研风格
**Best for**: 学术报告, 论文答辩, 研究分享, 实验汇报, 学术会议, 基金申请

## Visual Identity
- Theme: `academic-paper.css`
- Texture: clean
- Mood: neutral
- Typography: editorial
- Density: balanced

## Layout Preferences
- Cover: `cover`（论文标题 + 作者/机构 + 会议/日期）
- Content: `bullets`, `two-column`, `three-column`
- Code: `code`（学术代码块，非主要用途）
- Data: `chart-line`, `chart-bar`, `table`, `chart-radar`

## Animation
- Entry: `fade-in`
- Transitions: 极简淡入，无装饰动画（学术场合禁用过度动画）
- Canvas FX: none

## Signal Keywords
研究, 实验, 方法, 数据, 结论, 论文, 学术, 答辩, 博士, 硕士, 基金, 课题, 文献, 综述, 消融, baseline

## When to Use
学术会议报告、论文答辩或研究分享。scientific preset 遵循学术演示规范：一页一观点、结论页（非致谢）、克制动画。

## When NOT to Use
商业演示或产品发布，学术风格过于保守，缺乏商业演示所需的情感感染力。
