# Editorial Infographic (编辑信息图)

**Style**: 杂志编辑排版 + 信息图元素混合，高密度信息呈现，适合数据驱动的内容出版物
**Best for**: 数据报告, 行业分析, 白皮书演示, 信息图表, 年度数据回顾

## Visual Identity
- Theme: — (custom: 白底或浅灰底，衬线标题，几何无衬线正文，数据色板丰富)
- Texture: clean
- Mood: neutral
- Typography: editorial
- Density: dense

## Layout Preferences
- Cover: `cover`（杂志封面风格：大标题 + 摘要 + 出版信息）
- Content: `bullets`, `three-column`, `two-column`
- Code: N/A（非主要用途）
- Data: `kpi-grid`, `chart-line`, `chart-bar`, `chart-pie`, `table`, `stat-highlight`

## Animation
- Entry: `fade-in`
- Transitions: 简洁淡入，内容主导
- Canvas FX: none

## Signal Keywords
数据, 分析, 趋势, 统计, 指标, 报告, 行业, 市场研究, 白皮书, 年度回顾, 信息图

## When to Use
数据密集的报告演示，需要在有限页数内展示多维度的数据和洞察。编辑排版确保信息层级清晰，信息图元素提升数据可读性。

## When NOT to Use
简短演讲或单观点输出场景，高密度排版会让观众感到压迫，降低信息吸收率。
