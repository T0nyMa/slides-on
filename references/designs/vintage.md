# Vintage (复古经典)

**Style**: 泛黄纸张 + 衬线字体 + 暖棕墨色，传递历史厚重感和经典美学
**Best for**: 历史文化, 经典文学, 品牌传承, 怀旧主题, 高端工艺品

## Visual Identity
- Theme: — (custom: 泛黄米色底 `#f4ecd8`，深棕墨色主文字，暗红/金褐强调，旧纸张纹理叠加)
- Texture: organic
- Mood: warm
- Typography: editorial
- Density: balanced

## Layout Preferences
- Cover: `cover`（装饰性衬线标题 + 花纹边框）
- Content: `bullets`, `big-quote`, `two-column`
- Code: N/A
- Data: `table`, `chart-bar`

## Animation
- Entry: `fade-in`
- Transitions: 缓慢淡入，模拟翻旧书页
- Canvas FX: `noise-field`

## Signal Keywords
历史, 经典, 传统, 传承, 怀旧, 复古, 文化遗产, 工艺, 经典文学, 时光, 岁月

## When to Use
历史、文化、高端品牌传承主题的演示。vintage 风格与内容主题形成一致的美学编码。

## When NOT to USE
现代科技或商业数据分析，复古风格与内容形成认知冲突，降低信息可信度。
