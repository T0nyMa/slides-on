# Pixel Art (像素艺术)

**Style**: 像素网格 + 8-bit 字体 + 高饱和色彩，致敬经典电子游戏和早期计算机文化
**Best for**: 游戏主题, 像素文化, 复古科技, 电子音乐, 独立游戏开发, 创意编程

## Visual Identity
- Theme: — (custom: 像素化背景图案，高饱和色板，8-bit 像素字体 `Press Start 2P`，可见像素网格线)
- Texture: pixel
- Mood: cool
- Typography: technical
- Density: balanced

## Layout Preferences
- Cover: `cover`（像素大标题 + 8-bit 风格）
- Content: `bullets`, `two-column`
- Code: `code`（像素终端风格）
- Data: `chart-bar`（像素条柱），`stat-highlight`

## Animation
- Entry: `slide-down`
- Transitions: 从上方掉落，模拟 8-bit 游戏转场
- Canvas FX: `matrix-rain`, `noise-field`

## Signal Keywords
游戏, 像素, 复古, 8-bit, 16-bit, 独立游戏, 电子音乐, 创意编程, 复古科技, chiptune

## When to Use
游戏文化、像素艺术或复古科技主题的演示。受众通常对此风格有明确的审美期待。

## When NOT to Use
任何非游戏/非复古主题的演示。像素字体在中文环境下可读性较差，不适用于长文内容。
