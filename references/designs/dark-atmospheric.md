# Dark Atmospheric (暗色氛围)

**Style**: 深黑渐变背景 + 高对比亮色文字 + 霓虹点缀，营造沉浸式科技感和神秘氛围
**Best for**: 技术分享（晚间/线上）, 产品技术揭秘, 沉浸式演讲, 概念展示

## Visual Identity
- Theme: — (custom: 深黑 `#0a0a0f` 到深蓝黑渐变，霓虹青/紫强调 `#00d4ff` / `#a855f7`，高对比白字)
- Texture: clean
- Mood: dark
- Typography: geometric
- Density: minimal

## Layout Preferences
- Cover: `cover`（深色背景 + 发光标题）
- Content: `big-quote`, `bullets`, `two-column`
- Code: `code`, `terminal`（终端绿或霓虹青配色）
- Data: `stat-highlight`, `chart-bar`

## Animation
- Entry: `fade-in`
- Transitions: 缓慢淡入，保持沉浸感
- Canvas FX: `particle-burst`, `galaxy`, `light-trail`

## Signal Keywords
技术, 未来, 概念, 产品揭秘, TechTalk, 晚间分享, 深色模式, 沉浸式, 系统, 底层

## When to Use
晚间技术分享会、产品技术揭秘、或任何希望营造沉浸式科技氛围的演讲。深色背景减少观众视觉疲劳，适合长时间观看。

## When NOT to Use
白天投影场景（环境光强时深色背景对比度下降），或需要打印的文档。
