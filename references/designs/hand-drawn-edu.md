# Hand-Drawn Education (手绘教学)

**Style**: 纸纹理背景 + 手绘边框 + 马克笔配色 + 手写字体，模拟白板/笔记本教学风格
**Best for**: 教学课件, 培训材料, 知识分享, 工作坊, 在线课程, 入门教程

## Visual Identity
- Theme: — (custom: 米白纸纹理底，黑色手写主色，马克笔强调色（橙/蓝/绿），手绘不规则边框)
- Texture: paper
- Mood: warm
- Typography: handwritten
- Density: balanced

## Layout Preferences
- Cover: `cover`（手绘标题 + 笔记本格线装饰）
- Content: `bullets`, `two-column`, `three-column`, `todo-checklist`
- Code: `code`（手写风格注释，非主要用途）
- Data: `chart-bar`, `chart-pie`（手绘风格）

## Animation
- Entry: `slide-left`
- Transitions: 从侧边滑入，模拟"翻页"
- Canvas FX: `ink-drop`

## Signal Keywords
学习, 基础, 入门, 练习, 教程, 指南, 教学, 课件, 培训, 知识, 理解, 掌握, 快速上手

## When to Use
教学和培训场景，特别是面向初学者或需要降低学习心理门槛的内容。手绘风格天然传递"允许犯错"的友好信号。

## When NOT to Use
正式学术答辩或客户提案，手绘风格显得不够权威和严谨。
