# Vector Illustration (矢量插画)

**Style**: 扁平矢量插画 + 高饱和色块 + 圆角几何造型，现代感强烈的数字化视觉语言
**Best for**: 产品介绍, 品牌宣传, 创意提案, 设计展示, 科技产品, App 演示

## Visual Identity
- Theme: — (custom: 干净底色（白/浅灰），高饱和渐变色块装饰，圆角卡片，扁平阴影，几何无衬线字体)
- Texture: clean
- Mood: vibrant
- Typography: geometric
- Density: balanced

## Layout Preferences
- Cover: `cover`（矢量插画背景 + 大标题）
- Content: `bullets`, `three-column`, `two-column`
- Code: N/A（非主要用途）
- Data: `kpi-grid`, `stat-highlight`, `chart-bar`

## Animation
- Entry: `scale-in`
- Transitions: 缩放弹入，节奏明快
- Canvas FX: `boids`（可选）

## Signal Keywords
产品, 品牌, 设计, 创意, 现代, App, 用户体验, UI, 科技, 数字, 平台, 解决方案

## When to Use
科技产品和品牌创意展示，矢量风格传递现代、数字化、设计导向的品牌形象。

## When NOT to Use
学术报告或传统企业培训，矢量插画风格可能显得过于"设计感"，与严肃内容不匹配。
