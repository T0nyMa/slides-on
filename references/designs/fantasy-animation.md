# Fantasy Animation (奇幻动画)

**Style**: 梦幻插画风格 + 暖色渐变 + 手写字体 + 丰富动画，充满想象力和故事感
**Best for**: 创意故事, 品牌概念, 儿童内容, 游戏叙事, 艺术展示

## Visual Identity
- Theme: — (custom: 暖色梦幻渐变底（粉橙紫），手写标题字体，星点/光晕装饰元素)
- Texture: organic
- Mood: vibrant
- Typography: handwritten
- Density: minimal

## Layout Preferences
- Cover: `cover`（故事标题 + 魔法氛围背景）
- Content: `big-quote`, `bullets`
- Code: N/A
- Data: N/A（不常用数据展示）

## Animation
- Entry: `scale-in`
- Transitions: 缩放弹入，节奏轻快
- Canvas FX: `particle-burst`, `fireworks`, `galaxy`, `snow`, `confetti`

## Signal Keywords
故事, 奇幻, 梦想, 魔法, 冒险, 创意, 幻想, 童话, 游戏, 动画, 儿童, 艺术

## When to Use
以叙事和视觉体验为核心的创意演示，特别是面向年轻观众或需要激发想象力的场景。

## When NOT to Use
任何需要传递严谨、专业或权威感的内容。动画效果在投影较差的环境可能表现不佳。
