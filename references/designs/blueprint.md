# Blueprint (蓝图技术)

**Style**: 蓝图网格线配合蓝色等宽字体，传递精确的工程感与技术架构感
**Best for**: 技术架构分享, 系统设计文档, 代码/API 演示, 开源项目介绍, 基础设施说明

## Visual Identity
- Theme: `blueprint.css`
- Texture: grid
- Mood: dark
- Typography: technical
- Density: balanced

## Layout Preferences
- Cover: `cover`（居中标题 + 网格线装饰）
- Content: `bullets`, `two-column`
- Code: `code`, `terminal`
- Data: `arch-diagram`, `flow-diagram`, `chart-bar`

## Animation
- Entry: `fade-in`
- Transitions: 简洁淡入，无过度动画
- Canvas FX: `circuit`（可选）

## Signal Keywords
代码, 架构, API, 系统设计, 开源, 框架, 技术架构, 基础设施, 后端, 微服务, 数据库, 协议, SDK, CLI

## When to Use
技术分享或系统架构演讲，需要传递精确、工程化的专业感。深色蓝图背景让代码块和架构图表现极佳。

## When NOT to Use
非技术类内容（如商业汇报、教学课件）使用 blueprint 会显得过于冷硬，缺乏亲和力。
