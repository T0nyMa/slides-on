# Intuition Machine (直觉机器)

**Style**: 蓝图网格 + 技术等宽字体 + 高密度信息，传递工程思维的深度技术文档风格
**Best for**: 技术深度分享, 系统设计评审, 工程文档, 性能分析, 架构决策记录

## Visual Identity
- Theme: `blueprint.css`
- Texture: grid
- Mood: dark
- Typography: technical
- Density: dense

## Layout Preferences
- Cover: `cover`（技术标题 + 版本号/日期元信息）
- Content: `bullets`, `two-column`, `three-column`
- Code: `code`, `terminal`, `diff`
- Data: `arch-diagram`, `flow-diagram`, `table`, `gantt`

## Animation
- Entry: `fade-in`
- Transitions: 极简淡入，无装饰动画
- Canvas FX: `circuit`, `grid-pulse`

## Signal Keywords
系统, 架构, 性能, 深度, 底层, 设计评审, 技术决策, ADR, 工程, 协议, 算法, 数据结构

## When to Use
面向技术同行的深度分享，需要展示大量技术细节、架构图和代码。dense 密度让单页承载更多信息，适合会后阅读。

## When NOT to Use
面向非技术受众的演示，蓝图美学和高密度会让普通观众感到疏离和困惑。
