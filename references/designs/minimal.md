# Minimal (极简主义)

**Style**: 白底黑字 + 几何无衬线 + 极简布局，去一切装饰，只留内容本身
**Best for**: 技术分享, 学术报告, 周报汇报, 内部沟通, 极简设计展示

## Visual Identity
- Theme: `minimal-white.css`
- Texture: clean
- Mood: neutral
- Typography: geometric
- Density: minimal

## Layout Preferences
- Cover: `cover`（标题 + 作者 + 日期，无装饰）
- Content: `bullets`, `big-quote`, `two-column`
- Code: `code`, `terminal`
- Data: `chart-line`, `chart-bar`, `stat-highlight`, `table`

## Animation
- Entry: `fade-in`
- Transitions: 极简淡入，无任何多余动画
- Canvas FX: none

## Signal Keywords
技术, 代码, 开源, 框架, 周报, 进展, OKR, 复盘, 学术, 研究, 论文, 极简

## When to Use
任何希望内容本身成为绝对焦点的场景。极简风格是最安全的通用选择，不会因为风格偏好而引起任何受众不满。

## When NOT to Use
需要视觉感染力或品牌个性化表达的演示，极简风格可能显得过于朴素、缺乏记忆点。
