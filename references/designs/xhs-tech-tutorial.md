# XHS Tech Tutorial (小红书技术教程)

**Style**: 纯白底 + 粗黑标题 + 手绘插图配图 + 高信息密度，技术知识科普信息图风
**Best for**: 技术教程, AI/编程知识科普, 工具指南, 框架入门, 概念图解

## Visual Identity
- Theme: custom
- Texture: clean
- Mood: professional
- Typography: geometric (系统黑体, weight 900)
- Density: dense

## Signature Elements
1. **纯白底无纹理**: 与 hand-drawn-edu（纸质纹理）、sketch-notes（牛皮纸）明确区分
2. **超粗黑标题**: weight 900，每页顶部大字标题，视觉冲击力强
3. **手绘插图区**: 页面左侧或内联的插图占位/配图区域（AI 后期生成水彩墨线风格）
4. **彩色标签徽章**: 小色块标签用于分类（绿/蓝/橙/红四色）
5. **步骤连接箭头**: 蓝色下箭头 + 右侧提示语，连接顺序步骤
6. **彩色边框卡片**: 左边框或全边框的卡片，颜色区分类别
7. **高信息密度**: 每页内容量大，接近信息图而非演示文稿

## Layout Preferences
- Cover: 副标题 + 大标题（多色高亮）+ 大插图区 + 底部归属/徽章
- Step-flow: 垂直步骤序列（左插图 + 右文字 + 箭头连接）
- Icon-list: 左插图 + 右标题描述的重复行列表
- Section-boxes: 多个带标题的边框区块堆叠
- Mixed-cards: 彩色卡片网格 + 警告框 + 对比列

## Typography
- 标题: 系统黑体 (PingFang SC / Microsoft YaHei), 900 weight, 近黑
- 正文: 同上 sans-serif, 400-500 weight
- 英文标题: 同字体，700-900 weight（非 serif italic）
- 强调: 彩色标签，非粗体文字强调
- 密度高，字号偏大，行高紧凑

## Animation
- Entry: none（静态信息图风格）
- Transitions: minimal fade
- Canvas FX: none

## Signal Keywords
教程, 入门, 指南, 从零, 搭建, Agent, AI, 工具, 框架, 原理, 实战, 新手, 图解

## When to Use
技术知识科普、AI/编程教程、工具使用指南、概念图解。适合小红书/公众号图文场景，高信息密度让每页都有干货。

## When NOT to Use
正式商业演示（太信息图化）、纯文字内容（需要插图配合才好看）。
