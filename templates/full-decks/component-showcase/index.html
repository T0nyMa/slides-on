Five Agent Types

🔍
Research Agent
Gather info + summarize. Web search + structured output
✏️
Content Agent
Write, rewrite, transform. Strong system prompt + style examples
⚙️
Workflow Agent
Execute fixed business processes. Clear rules + API integration
📋
Knowledge Agent
Answer from your docs. File search or RAG
🔧
Operator Agent
Execute actions in environment. Tools + permissions + safety

Core Concepts

LLM = Brain
Handles reasoning and decision-making in the agent loop
Tools = Hands
Execute search, compute, file I/O, API calls
Memory = Notebook
Conversation history and persistent context
Guardrails = Safety
Rules and boundaries the agent must respect

Agent Formula

Agent = Role + Goal + Tools + Rules + Output
Example
Role: Crypto Research Assistant
Goal: Find accurate info and summarize clearly
Tools: Web Search, File Search, Calculator
Rules: Cite sources, mark uncertainty
Output: Summary + Risk + Opportunity + Verdict
💡
Pro Tip
Start simple. Most agents work fine with just a clear prompt + one tool.
Add complexity only when the task genuinely requires it.
⚠️
Over-engineering Warning
Don't add vector DB before confirming you need memory.
Don't use multi-agent before a single agent works.
Golden rule: if it runs without it, don't add it.
The best agent is the simplest one that gets the job done. Start with a single prompt, add complexity only when the task demands it.
— Anthropic Agent Design Guide, 2025
