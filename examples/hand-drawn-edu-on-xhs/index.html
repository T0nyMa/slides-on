Layer 4 · 多路导出

Playwright @2x 截图 → PNG → merge-to-pptx / merge-to-pdf；或 pptxgenjs 原生 .pptx 生成

三条 导出路径
用户自由选择

路径 A · 图片拼合式

HTML → Playwright @2x 精确截图 → 高质量 PNG → merge-to-pptx.ts → .pptx
优点：视觉保真度高，所见即所得 | 缺点：文本不可编辑

路径 B · 原生 PPTX 生成

outline.md → pptxgenjs 代码生成 → 原生 .pptx（AI 插图/SVG 图作为图片嵌入）
优点：文本图表完全可编辑 | 缺点：视觉受 pptxgenjs 能力限制

路径 C · 混合式 ⭐ 推荐

文字页 → pptxgenjs 原生生成（可编辑）+ 架构图页 → SVG → PNG 嵌入 + 插图页 → AI 生成嵌入 + 复杂排版页 → HTML 截图嵌入
优点：兼顾可编辑性 + 视觉表现力
