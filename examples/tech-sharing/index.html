Type-safe RPC with Hono

// api/routes/users.ts — Hono RPC route
import { Hono } from 'hono';
import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';

const app = new Hono()
  .get('/:id', async (c) => {
    const { id } = c.req.param();
    const user = await db.query.users
      .findFirst({ where: eq(users.id, id) });
    return c.json({ data: user });
  })
  .post('/', zValidator('json', z.object({
    name: z.string().min(2),
    email: z.string().email(),
  })), async (c) => {
    const body = c.req.valid('json');
    const user = await db.insert(users)
      .values(body).returning();
    return c.json({ data: user }, 201);
  });

export type UsersRoute = typeof app;
export default app;

Summary

Key Takeaways

  • Bun is production-ready — Native TypeScript, faster installs, built-in test runner make it the default choice for new projects.
  • Type-safe RPC eliminates API drift — With Hono RPC and Zod, client and server stay in sync automatically.
  • Edge computing reduces latency — Deploying API handlers at the CDN edge cuts TTFB by 40-60% for global users.
  • ORM type-safety catches bugs at compile time — Drizzle ORM provides end-to-end type safety from schema to response.
