# Editorial Infographic — AI Image Style Definition

Data-rich editorial infographic style. Structured layouts, clean typography, clear visual hierarchy. Like a well-designed magazine information graphic or a premium news data visualization.

## Style Lock (跨页复用)

```text
Clean editorial infographic on off-white newsprint (#F9F8F6) with subtle paper texture.
Structured data-visualization aesthetic: charts, tables, flow diagrams, comparison matrices.
Muted professional palette: deep navy #1A2332, slate grey #5A6B7D, warm accent #D4754B.
Light pastel data blocks: pale blue #D6E5F0, pale green #D4E8D4, pale yellow #F5EED5, pale rose #F0DCD5.
Thin precise ruled lines (0.5–1px): data table borders, chart axes, connector lines.
Clean sans-serif typography throughout: variable weights for hierarchy.
Small data-point markers: dots, small circles, tick marks. Crisp line charts and bar charts.
Generous but structured whitespace (30–40%). Modular grid: 2–3 columns of data cards.
Subtle divider rules between sections. Page number and source line in footer (small, light grey).
Data labels near data points, not floating. Consistent measurement scale across all charts.
No hand-drawn wobble, no cartoon elements, no thick lines, no saturated colors, no decorative doodles, no photorealistic images, no 3D charts, no clip art.
```

## Visual Elements

- Thin precise ruled lines for table borders, chart axes, and connector lines
- Clean line charts: plotted data points connected by thin navy lines, small dot markers
- Simple bar charts: horizontal or vertical, pale pastel fill, thin outline
- Circular data indicators: semi-circular gauges, pie segments with thin dividers
- Data tables with thin grid lines and alternating row tints
- Small annotation markers: dots, tick marks, geometric indicators
- Timeline connectors: horizontal lines with node markers and date labels
- Modular card layout: 2–3 column grid of data cards with thin borders
- Flow arrows: thin, straight, with clean arrowheads
- Subtle horizontal divider rules between sections
- Page number + source line in footer (small, light grey, right-aligned)

## Typography

- Clean modern sans-serif throughout — data journalism aesthetic
- Variable weights for hierarchy: bold titles, medium section heads, regular body
- Small condensed labels near data points
- Source citations in 7–8pt light grey at bottom
- Numbers in proportional lining figures
- NO serif, NO handwritten, NO decorative, NO cartoon fonts

## Composition

- Structured modular grid: 2–3 columns, clear horizontal sections
- Title at top, left-aligned or centered, with thin underline
- Whitespace 30–40% — structured, not empty
- Data visualizations occupy 60–70% of content area
- Consistent spacing rhythm: equal column gaps, consistent section margins
- Footer line at bottom: page number left, source right
- Fixed shell: paper tone, grid system, typography scale, line weight, palette

## Negative Constraints

- NO hand-drawn wobble, NO irregular lines — precision is essential
- NO cartoon elements, NO mascots, NO cute illustrations
- NO thick lines (maximum 1.5px), NO chunky charts
- NO saturated colors, NO neon, NO bright primaries
- NO 3D charts, NO isometric views, NO faux 3D effects
- NO photorealistic images, NO stock photos
- NO clip art, NO decorative icons, NO emojis
- NO dark backgrounds — keep off-white paper
- NO gradient fills in charts, NO drop shadows
- NO text-heavy walls — data visualizations should dominate
