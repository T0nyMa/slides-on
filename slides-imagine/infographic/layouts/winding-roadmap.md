# Winding Roadmap

**Best for**: Vision roadmaps, journeys with milestones, and strategic paths
**Structure**: A curving path or road that winds across the canvas, with milestone markers positioned along the road. The path is not straight — it curves to suggest a journey with direction changes
**Elements**: Winding road/path, milestone markers (flags, pins, or nodes), milestone labels with dates or phases, optional terrain/landscape context, starting point and destination indicators

## Content Requirements
- A journey or progression with 4-8 milestones
- Each milestone: phase name, brief description, and optionally a target date
- A clear starting point and a defined destination or vision
- The winding path should reflect real direction changes or phases (not arbitrary curves)

## When to Use
- Product or technology roadmaps
- Strategic vision presentations
- Career or learning journey narratives
- Multi-phase transformation programs

## When NOT to Use
- Straight-line timelines — use linear-progression
- When the "winding" aspect is purely decorative (straight line would work fine)
- When precise dates and linear time are the primary message (use linear-progression)
