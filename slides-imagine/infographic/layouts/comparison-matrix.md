# Comparison Matrix

**Best for**: Multi-dimensional comparison across multiple items and criteria
**Structure**: A 2D matrix/table with items as rows and evaluation criteria as columns. Cells can contain checkmarks, ratings, short text, or color-coded indicators
**Elements**: Row headers (items), column headers (criteria), cell indicators, optional row/column highlights, legend

## Content Requirements
- 3-8 items to compare
- 2-6 comparison criteria or dimensions
- Comparable data for each cell (ratings, binary yes/no, qualitative levels)
- Criteria should be independent dimensions

## When to Use
- Feature comparison across products or approaches
- Technology or tool evaluation against requirements
- Capability assessment across teams or systems
- Multi-factor decision-making analysis

## When NOT to Use
- Comparing only two items — use binary-comparison
- When items share no common criteria for comparison
- When the comparison data is primarily narrative rather than categorical
