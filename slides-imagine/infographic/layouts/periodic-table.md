# Periodic Table

**Best for**: Taxonomies, categorized listings, and systematic classification of items
**Structure**: A grid of categorized cells arranged like the periodic table of elements. Items are grouped by category (color-coded) and positioned in a structured grid layout. Each cell contains a compact item identifier
**Elements**: Cell grid, category color coding, cell labels (short codes + names), category legend, group/period labels

## Content Requirements
- 12-50+ items organized into 4-10 categories
- Each item: a short identifier (1-4 chars) + a brief label
- Categories should be meaningful groupings with clear membership rules
- Items should be systematically classifiable (like chemical elements)

## When to Use
- Technology or tool landscape taxonomies
- Feature or capability catalogs grouped by type
- Risk or threat classification matrices
- Any large set of items that can be systematically categorized

## When NOT to Use
- Small item sets (< 12 items) — use bento-grid or dense-modules
- When items cannot be clearly categorized
- When each item needs more than a label (long descriptions won't fit in cells)
- When the periodic table metaphor feels forced or gimmicky
