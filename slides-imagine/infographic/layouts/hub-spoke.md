# Hub Spoke

**Best for**: Ecosystem overviews, platform diagrams, and centralized architectures
**Structure**: A central hub node in the middle with multiple spokes radiating outward to peripheral nodes. The hub represents the core entity; spokes represent connections to related entities
**Elements**: Central hub (larger, prominent), peripheral nodes (smaller), connecting lines/spokes, node labels, optional bidirectional arrows

## Content Requirements
- One clear central entity (platform, core system, central team)
- 4-10 peripheral entities that connect to the center
- Description of what flows along each spoke (data, dependencies, communication)
- Peripheral nodes should be peers (same level of importance)

## When to Use
- Platform ecosystem diagrams (central platform + integrations)
- Hub-and-spoke architecture or distribution models
- Centralized team/service with multiple dependent consumers
- Strategic overview with one core and many satellites

## When NOT to Use
- Decentralized or mesh networks (no clear center)
- Sequential or staged relationships — use linear-progression
- When peripheral nodes have strong relationships with each other (not just the hub)
