# Dashboard

**Best for**: Metrics display, KPI overviews, and data monitoring snapshots
**Structure**: Tile-based arrangement resembling a monitoring dashboard, with large metric cards prominently displayed. Typically includes big numbers, sparklines, and status indicators
**Elements**: KPI tiles with large numbers, trend indicators (up/down arrows), mini sparklines or bar charts, status colors (green/red/amber), labels

## Content Requirements
- 4-9 key metrics or KPIs
- Each metric needs: a value (number), a label, and optionally a trend/change indicator
- Metrics should tell a coherent story about performance or status
- Can include simple time-series sparklines for context

## When to Use
- Executive summaries or status reports
- System health or performance monitoring views
- Quarterly/annual business reviews
- Any scenario where "at-a-glance" numeric data is the primary message

## When NOT to Use
- When the primary message is narrative rather than quantitative
- When metrics lack clear meaning without extensive context
- When you need to show relationships between metrics rather than individual values
