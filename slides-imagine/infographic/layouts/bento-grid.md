# Bento Grid

**Best for**: Multiple related features, stats, or product highlights presented as a unified showcase
**Structure**: A grid of rounded-rectangle modules of varying sizes, like bento box UI cards. Cells can span different rows/columns to create visual hierarchy
**Elements**: Rounded-rect cards, icons, short metrics, one-line descriptions, subtle shadows

## Content Requirements
- 4-9 discrete items, each with a short title, optional metric/KPI, and 1-2 line description
- Items should be loosely related under a common theme
- Each card must be self-contained; no strong sequential dependency between cards

## When to Use
- Showcasing a product's feature set or a platform's capabilities
- Displaying a set of key metrics or stats that share a common theme
- Presenting a "snapshot" overview where items have equal importance but different sizes

## When NOT to Use
- When items have a strong sequential or hierarchical relationship — use linear-progression or tree-branching instead
- When you have more than ~12 items — the grid becomes cluttered
- When individual items require long explanations
