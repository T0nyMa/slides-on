# Comic Strip

**Best for**: Storytelling, step-by-step narratives, and scenarios that benefit from a visual narrative format
**Structure**: Sequential panels arranged left-to-right (or top-to-bottom), like a comic strip. Each panel contains a scene or step, often with a visual and a caption
**Elements**: Framed panels, scene illustrations, speech/thought bubbles, captions, panel numbering

## Content Requirements
- A narrative with 3-6 clear sequential scenes or steps
- Each panel should communicate one idea or moment
- Visual or diagrammatic representation for each scene
- A narrative arc: setup, development, resolution

## When to Use
- User journey or customer experience stories
- Before/after transformation narratives with intermediate steps
- Explaining a concept through a relatable scenario
- Process documentation where each step has a distinct "scene"

## When NOT to Use
- Pure data or metric displays — use dashboard or bento-grid
- Abstract concepts without a narrative thread
- When the sequence has more than ~8 steps — becomes too long for a comic strip
