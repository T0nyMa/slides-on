# Architecture Diagram（系统架构图）

用于展示软件系统、服务拓扑、数据管道或基础设施的组件关系与分层结构。

## 适用场景

| 场景 | 示例 |
|------|------|
| 微服务拓扑 | 服务注册 → API 网关 → 业务服务 → 数据库 |
| 数据管道 | 数据源 → 消息队列 → 流处理 → 存储 → 分析 |
| 客户端-服务端分层 | App → CDN → 负载均衡 → 应用服务器 → 缓存/DB |
| ML 推理管线 | 特征工程 → 模型推理 → 后处理 → 结果返回 |
| 云基础设施 | VPC → 子网 → 计算实例 → 存储卷 |

## 典型视觉结构

- **组件框**：圆角矩形（rx=6），代表服务/模块/应用
- **数据库**：圆柱体形状，代表持久化存储
- **层级区域**：大虚线或浅色背景框，将相关组件分组（如"数据层""服务层""接入层"）
- **箭头**：带箭头的实线或虚线，表示数据流、API 调用或依赖关系
- **标签**：组件名称、技术栈标注、协议标注（HTTP/gRPC/Kafka）

## 布局模式

```
【常用布局 A — 自上而下分层】
┌────────────────────────────────────┐
│           接入层 (Client)           │
├────────────────────────────────────┤
│           服务层 (Service)          │
├────────────────────────────────────┤
│           数据层 (Data)             │
└────────────────────────────────────┘

【常用布局 B — 左右分区】
┌──────────┬──────────┬──────────┐
│  Frontend │  Backend  │  Storage │
└──────────┴──────────┴──────────┘
```

## z-order 分层规则

SVG 元素严格按以下顺序从底到顶绘制（后面元素覆盖前面）：

```
Layer 1: 背景 (Background)
  └── 深色画布填充 (#0f172a)

Layer 2: 区域边界 (Region Boundaries)
  └── 层级/分区背景框（虚线矩形，低透明度填充）

Layer 3: 连接箭头 (Connection Arrows)
  └── 数据流、API 调用、依赖关系线
  └── 箭头标记（实心三角 = 同步调用，开放三角 = 异步）

Layer 4: 遮罩矩形 (Mask Rectangles)
  └── 覆盖在箭头穿过组件区域之上的白色遮罩
  └── 避免箭头穿入组件框内部

Layer 5: 组件框 (Component Boxes)
  └── 服务/模块圆角矩形，填充 + 描边
  └── 数据库圆柱体
  └── 图标（可选，内嵌或左对齐）

Layer 6: 文本标注 (Text Labels)
  └── 组件名称（居中，粗体）
  └── 技术栈/协议标注（小字号，副色）
  └── 区域标题（层级标签，位于区域框左上角）

Layer 7: 图例 (Legend)
  └── 右下角或左下角色块 + 文字说明

Layer 8: 标题 (Title)
  └── 顶部居中或左上角，大字号
```

## 语义配色（8 色系统）

| 色号 | 名称 | 色值 | 用途 |
|------|------|------|------|
| Primary | 蓝 | `#60a5fa` | 核心服务、入口组件 |
| Secondary | 紫 | `#a78bfa` | 辅助服务、中间件 |
| Tertiary | 绿 | `#34d399` | 数据存储、缓存、成功状态 |
| Accent | 粉 | `#f472b6` | 外部依赖、第三方服务 |
| Alert | 橙 | `#fb923c` | 异步队列、消息中间件、注意点 |
| Connector | 灰 | `#94a3b8` | 连接线、箭头、边框 |
| Neutral | 深灰 | `#334155` | 组件背景填充 |
| Highlight | 黄 | `#fbbf24` | 关键路径高亮、标注 |

## 何时选择 Architecture Diagram

- **选择此类型**：需要展示系统有哪些组件、它们之间如何连接、分层关系
- **不用此类型**：如果重点是过程流转而非结构关系，用 Flowchart；如果是实体关系，用 Structural

## 与其他图型对比

| 对比项 | Architecture | Flowchart | Sequence | Structural |
|--------|:-----------:|:---------:|:--------:|:----------:|
| 主要表达 | 结构关系 | 过程决策 | 时间交互 | 层级组织 |
| 节点形状 | 方框/圆柱 | 多种形状 | 生命线 | 方块/节点 |
| 连线含义 | 依赖/调用 | 控制流 | 消息序列 | 归属/父子 |
