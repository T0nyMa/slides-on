# Flowchart Diagram（流程图）

用于展示算法逻辑、业务流程、决策树或数据处理流水线中的步骤顺序与分支路径。

## 适用场景

| 场景 | 示例 |
|------|------|
| 算法流程 | 排序算法、推荐召回的逐级过滤 |
| 业务审批流 | 提交 → 审核 → 通过/驳回 → 通知 |
| 数据处理链 | 清洗 → 归一化 → 特征工程 → 模型训练 |
| 故障排查 | 检查条件 → 分支处理 → 恢复/告警 |
| 用户决策流程 | 登录 → 权限判断 → 不同功能入口 |

## 典型视觉结构

每个节点使用不同的 SVG 形状标识其语义：

| 形状 | SVG 元素 | 语义 |
|------|---------|------|
| 圆角矩形 | `<rect rx="8">` | 开始/结束节点（Start/End） |
| 矩形 | `<rect rx="2">` | 处理步骤（Process） |
| 菱形 | `<polygon>` | 判断/分支（Decision） |
| 圆柱 | `<path>` | 数据存储（Data Store） |
| 平行四边形 | `<polygon>` | 输入/输出（I/O） |

**箭头**：带箭头的线段连接节点，表示控制流方向。主流自上而下，分支向右或左下展开。

## 布局模式

```
【基本流程 — 自上而下】
       ┌──────┐
       │ Start │
       └──┬───┘
          │
    ┌─────▼─────┐
    │  Process  │
    └─────┬─────┘
          │
     ┌────▼────┐
     │ Decision │
     └──┬───┬──┘
    Yes │   │ No
   ┌────▼┐ ┌▼───┐
   │  A  │ │ B  │
   └──┬──┘ └─┬──┘
      │      │
      └──┬───┘
      ┌──▼──┐
      │ End │
      └─────┘
```

## z-order 分层规则

```
Layer 1: 背景 (Background)
  └── 深色画布填充 (#0f172a)

Layer 2: 区域边界 (Region Boundaries)
  └── 泳道/阶段分组背景框（可选，如"预处理""推理""后处理"）

Layer 3: 连接箭头 (Connection Arrows)
  └── 步骤间控制流箭头
  └── 分支标签（Yes/No、True/False、条件表达式）
  └── 返回/循环线（虚线弧线，上绕回到先前节点）

Layer 4: 遮罩矩形 (Mask Rectangles)
  └── 箭头进入节点处的遮罩，保持视觉整洁

Layer 5: 节点框 (Process/Decision Nodes)
  └── 开始/结束圆角矩形
  └── 处理步骤标准矩形
  └── 判断分支菱形

Layer 6: 文本标注 (Text Labels)
  └── 节点内描述文字（居中，单行或多行）
  └── 分支条件标签（沿箭头标注）
  └── 步骤编号（可选，节点左上角小标）

Layer 7: 图例 (Legend)
  └── 形状 → 语义映射

Layer 8: 标题 (Title)
  └── 顶部居中
```

## 决策分支模式

```
【单条件二分支】          【多路分支 (Switch)】
      ◇                       ┌───────┐
     / \                      │ Value │
    /   \                     └───┬───┘
   A     B                 ┌──────┼──────┐
                          │      │      │
                        Case1  Case2  Case3

【循环模式】
    ┌──────┐
    │ Init │
    └──┬───┘
       │
   ┌───▼───┐     ┌──────────┐
   │ Loop  ├────▶│ Condition │
   │ Body  │     └────┬─────┘
   └──▲────┘     Yes  │   No
      │               │
      └───────────────┘   → Exit
      (回溯线，虚线，从侧面绕回)
```

## 语义配色

沿用 8 色系统，按节点语义分配：

| 节点类型 | 色号 | 说明 |
|---------|------|------|
| Start/End | Tertiary (#34d399) | 绿色表示入口/出口 |
| Process | Primary (#60a5fa) | 蓝色表示处理操作 |
| Decision | Accent (#f472b6) | 粉色强调决策点 |
| Data Store | Alert (#fb923c) | 橙色表示持久化 |
| Error/Exception | Alert (#fb923c) | 橙色强调异常路径 |
| 箭头/连线 | Connector (#94a3b8) | 灰色 |

## 何时选择 Flowchart

- **选择此类型**：需要展示"第一步做什么、第二步做什么、在什么条件下走哪个分支"
- **不用此类型**：如果重点是系统结构而非过程流程，用 Architecture；如果是时间顺序交互，用 Sequence

## 与其他图型对比

| 对比项 | Flowchart | Architecture | Sequence | Structural |
|--------|:---------:|:-----------:|:--------:|:----------:|
| 时间维度 | 有顺序，无时间轴 | 无 | 明确时间轴 | 无 |
| 分支逻辑 | 核心要素 | 无 | 可选（alt/opt） | 无 |
| 节点多样性 | 高（5+ 形状）| 低（2-3 种）| 低 | 中 |
